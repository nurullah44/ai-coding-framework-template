# Verdict template

> **Fill this in.** The shape of a review result, as a Reviewer writes it and the Builder and Coordinator read it.

## Questions to answer

- What are the possible results (for example pass, fail, could not verify)?
- Which version of the code does a verdict cover?
- How is each finding listed, with what evidence?
- How are blocking findings told apart from remarks?
- Where does the Reviewer say what it could not check?
