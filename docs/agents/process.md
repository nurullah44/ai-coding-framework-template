# Process

> **Fill this in.** How work moves from an idea to merged code: the roles, the models they run on, how big one piece of work may be, and the rules of the loop.

## Questions to answer

- Which roles exist? For each: what does it do, and what must it never do?
- Which model and effort does each role use, and why? Write them in a table so tools can read it.
- How big may one piece of work be? How do you measure it?
- What are the steps from idea to merge? Draw them.
- Which labels or states does a piece of work move through?
- When is a piece of work allowed to merge? Who merges it?
- What happens after a failed review? How many rounds before a human steps in?
- How much does a human check, and how does that change as trust grows?

Add a section per answer: Roles, Models, Work size, Flow, Labels, Rules, Autonomy.
